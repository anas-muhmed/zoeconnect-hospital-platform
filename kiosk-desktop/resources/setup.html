HDSP Kiosk Activation

Enter your HDSP server address and the activation code your HDSP administrator generated for this till (Kiosk Configuration -> Kiosk Devices). Use https:// for a public/internet address, or a plain http:// address on your hospital's own network (e.g. http://192.168.1.50:3000 or http://hdsp.hospital.local). Press Ctrl+Alt+K at any time to return to this screen.
