# ADR-013: Performance Budgets

**Status:** Accepted (Frozen — Phase 1–6 roadmap approved 2026-07-05)

## Context

Enterprise clinical forms can reach 100+ pages and thousands of controls; without explicit budgets, the canvas and renderer degrade silently as real hospitals adopt the platform.

## Decision

Concrete, testable targets are load-bearing requirements, not aspirations: virtualized canvas rendering (viewport-proportional, not document-proportional cost), a 200-field published form interactive in <2s on hospital LAN, <5s PDF generation for a 10-page submission, and CI-enforced performance tests against a synthetic 2,000-node/100-page schema (Phase 5A §10).

## Consequences

Performance regressions are caught in CI before merge, not discovered in a hospital's production Nursing Assessment form. Trade-off: some architectural decisions (grid-based spatial index over a full R-tree, Phase 5A §3) deliberately favor “simple and fast enough, documented as swappable” over premature optimization.
