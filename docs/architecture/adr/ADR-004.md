# ADR-004: Framework-Agnostic Canvas Engine

**Status:** Accepted (Frozen — Phase 1–6 roadmap approved 2026-07-05)

## Context

A naive canvas mounts one React component per placed field; this does not scale to the Phase 1 performance target (100+ pages, thousands of components) and couples the core editing model to React's render cycle.

## Decision

packages/canvas-engine (scene graph, spatial index, event bus, command system, viewport) is plain TypeScript with zero React/DOM dependency. React (canvas-engine-react) is a thin host that reads engine state via selector hooks and writes only via Command dispatch — never direct mutation.

## Consequences

Independently unit-testable headless (Phase 5A §10), scales by viewport size rather than document size, and could in principle support a non-React host later. Trade-off: more upfront structure than “just build it in React,” accepted deliberately per Phase 5A's mandate.

## Source
