# ADR-001: Schema-First Architecture

**Status:** Accepted (Frozen — Phase 1–6 roadmap approved 2026-07-05)

## Context

The platform could have been built component-first (canvas edits live React component instances directly) or schema-first (canvas edits a JSON document; components are a rendering of that document).

## Decision

Every form/document is, at its core, a versioned JSON Schema (FormSchema, Phase 2 §5). The canvas, the property panel, the rule engine, the renderer, and the PDF engine are all consumers or producers of this schema — none of them is the source of truth themselves.

## Consequences

Enables clean versioning, diffing, migration (ADR-009), multi-branch overrides (ADR-011), and a Builder/Renderer split (ADR-003) that would be structurally impossible in a component-first design. Trade-off: every new capability must be expressible in the schema, which is a constraint, not just a freedom.

## Source

Phase 2 §5; reaffirmed as the single most important decision in the project per Phase 6 closing assessment.
