# ADR-008: Configurable Workflow Engine

**Status:** Accepted (Frozen — Phase 1–6 roadmap approved 2026-07-05)

## Context

Different hospitals need different approval chains (a simple 3-step flow vs. a 7-step flow with Medical Director and Legal review).

## Decision

Workflow is a data-defined state machine (WorkflowDefinition/State/Transition/Instance, Phase 4A §3), not a hardcoded enum. The approved default 6-state flow (Draft→In Review→Approved→Published→Archived→Retired, Phase 1 §4.5) is seed data, not special-cased code.

## Consequences

New approval chains are configuration, not code changes. Simple hospitals see no added complexity (the default flow is indistinguishable from a hardcoded one in the common case). Trade-off: the engine itself must remain fully generic — it has zero knowledge of “forms” specifically.
