# ADR-007: Six-Stage Rendering Pipeline

**Status:** Accepted (Frozen — Phase 1–6 roadmap approved 2026-07-05)

## Context

Resolving branch/department overrides, layout, rules, permissions, and theming into a final render tree could be done ad hoc per component, or as a formal pipeline.

## Decision

Every render (Designer preview and production Runtime alike) passes through: Resolver → Layout Engine → Rule Engine → Permission Engine → Theme Engine → Renderer. Each stage is a pure, independently testable and cacheable function; only the final stage is React.

## Consequences

Preview-equals-runtime is structural, not tested-for. Each stage's performance and correctness can be reasoned about independently (Phase 3 §3.1's memoization guidance, Phase 6 §4 performance targets). Trade-off: a new cross-cutting concern must be placed in the correct stage rather than bolted onto a component.
